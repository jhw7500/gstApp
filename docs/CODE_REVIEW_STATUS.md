## 완료된 보안 수정 상세

### 001: 명령 인젝션 백도어 제거 ✅
- **위치**: parser.cpp:767-776
- **문제**: `bash -ic` 를 통한 임의 명령 실행
- **해결책**: 전체 코드 블록 삭제
- **커밋**: 3f01965 "security: Replace system() calls with safe alternatives"

### 002: AES 키 보안 강화 ✅
- **위치**: aes.cpp:262, 308
- **문제**: NIST 공개 테스트 벡터 사용 (0x2b7e1516...)
- **해결책**: 무작위 키로 교체 (0x2df5761a...)
- **커밋**: 8413fd5 "security: 하드코딩된 AES 키 교체 및 popen() 제거"

### 003: 바쁜 대기 루프 수정 ✅
- **위치**: main.cpp:1127
- **문제**: `g_main_context_iteration(loop, FALSE)` 무한 루프 (10% CPU 낭비)
- **해결책**: `g_main_loop_run(loop)` 블로킹 패턴 사용
- **커밋**: 5d28429 "fix: harden i2c exec and mkdir path checks"

### system() 호출 전체 교체 ✅
- **위치**: 12개 위치
- **해결책**:
  - `safe_write_file()` - 파일 쓰기
  - `safe_mkdir_p()` - 디렉토리 생성
  - `safe_exec_i2c()` - i2c 명령 실행 (fork + execvp)
- **커밋**: 3f01965

### popen() 셸 실행 제거 ✅
- **위치**: util.cpp:367
- **문제**: `popen("ls -ptr ... | grep ...")` 셸 명령
- **해결책**: GLib의 GDir API 사용 (g_dir_open, g_dir_read_name, stat)
- **커밋**: 8413fd5
